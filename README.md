# TCS UMKM Website Kit

**Fondasi website sederhana untuk memperkenalkan usaha dan informasi produk.**

- **Penerbit:** The Choco Studios (TCS)
- **Bahasa utama:** Bahasa Indonesia
- **Sasaran pengguna:** UMKM dan usaha lokal
- **Kategori:** Website dan kehadiran digital

## Ringkasan

TCS UMKM Website Kit dirancang sebagai titik awal bagi usaha yang ingin memiliki halaman web untuk memperkenalkan bisnis, menjelaskan produk atau layanan, menampilkan informasi kontak, dan mengarahkan calon pelanggan ke kanal komunikasi yang tepat.

## Ruang lingkup produk

Kit ini ditujukan untuk menyediakan fondasi website yang dapat disesuaikan dengan identitas usaha. Halaman, komponen, teknologi, integrasi, dan fitur yang benar-benar tersedia harus mengikuti isi repositori serta paket rilis aktual.

## Cara menggunakan

1. Unduh atau salin berkas dari rilis resmi.
2. Baca instruksi instalasi dan konfigurasi.
3. Ganti teks contoh, gambar, logo, kontak, dan informasi produk.
4. Periksa tautan, tampilan responsif, metadata, serta aksesibilitas.
5. Uji website pada perangkat dan browser yang relevan sebelum dipublikasikan.

## Sebelum dipublikasikan

Pastikan informasi harga, alamat, jam operasional, klaim produk, dan kontak benar. Gunakan gambar serta font sesuai hak penggunaan. Jika formulir mengumpulkan data pelanggan, jelaskan tujuan pengumpulan dan cara penanganannya.

## Batasan

Kit website tidak otomatis menyediakan hosting, domain, backend, pembayaran, penyimpanan data, atau integrasi pihak ketiga kecuali hal tersebut dinyatakan dan benar-benar tersedia dalam paket.

## Keamanan dan privasi

Jangan menaruh API key atau kata sandi di kode frontend. Integrasi formulir dan layanan eksternal harus diperiksa sebelum dipakai pada website publik.

## Dokumentasi

Lihat petunjuk setup, lisensi, changelog, dan daftar fitur dalam repositori.
